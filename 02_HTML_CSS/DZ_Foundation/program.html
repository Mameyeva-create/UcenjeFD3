Kurikulum FPV Akademije

Program je osmišljen kako bi polaznicima pružio teorijska i praktična znanja potrebna za sigurno upravljanje FPV dronovima.

  • Vrste dronova

    Upoznavanje s različitim vrstama FPV dronova, njihovom namjenom, osnovnim komponentama i pravilnim odabirom opreme.

  • Simulatori letenja

    Vježbanje upravljanja dronom u simulatorima kako bi se stekle osnovne vještine prije stvarnog leta.

  • Elektronika

    Osnove elektronike, baterija, motora, kontrolera leta i održavanja FPV opreme.
