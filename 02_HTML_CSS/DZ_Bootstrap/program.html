Kurikulum FPV Akademije

Program je osmisljen kako bi polaznicima pružio teorijska i praktična znanja potrebna za sigurno upravljanje FPV dronovima.

Program tečaja

Polaznici upoznaju osnovne dijelove FPV drona i uče kako pravilno sastaviti letjelicu.

  • Okvir drona
  • Motori i propeleri
  • Kontroler leta
  • ESC kontroleri
  • Baterija
  • FPV kamera i naočale

Sigurnost je jedan od najvažnijih dijlova FPV edukacije.

  • Sigurna priprema prije leta
  • Provjra opreme
  • Sigurno rukovanje baterijama
  • Pravila ponašanja tijekom leta
  • Osnovna pravila i odgovornost pilota

Polaznici kroz praktične vijžbe razvijaju osnovne pilotske vještine.

  • Osnovne kontrole leta
  • Polijetanje i slijetanje
  • Let ravno i u zavojima
  • Kontrola visine
  • Praktične vježbe u simulatoru
  • Prvi samostalni let

Polaznici uče osnovno održavanje i prepoznavanje najčešćih problema.

  • Pregled drona nakon leta
  • Zamjena propelera
  • Osnovno oderžavanje motora
  • Provjera baterije
  • Prepoznavanje osnovnih kvarova
